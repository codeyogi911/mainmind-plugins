# Mainmind for Codex

Continue with your agents and the work they remember, wherever you use AI.

Install `mainmind@mainmind` from the Mainmind marketplace, then sign in to your
Mainmind space. Ask “what's in my space?” to check the connection, or say
“Continue with Job Hunter” to pick up with an agent.

This package includes seven skills and the Mainmind connection at
`https://mainmind.app/mcp`. The skills teach Codex how to use your space's
knowledge and keep agent work in sync. The connection asks you to sign in;
the plugin carries no passwords or keys.
